# 健康钟 · dsh-clock

> 🐣 一个会催你"起来动一动"的 DSH 小插件。

你坐在电脑前敲键盘、看屏幕，一坐就是大半天。健康钟会在你连续工作后，
把 DSH 窗口叫到最前面，弹出一张卡通卡片，带你做一套 **12～15 分钟**的休息计划：
10 秒准备 → 按步骤倒数 → 拉伸收尾。做完计时归零，进入下一轮。

> 📌 **当前状态：v1.3.1（2026-10-18，迭代 4）**
> - ✅ 设置页：**工作时长**（5～120 分钟）、**休息时长**（跟随计划 / 固定 5～30 分钟）、**弹窗大小**（100%～200%，默认 150%）都能调；
> - ✅ **12 套内置计划**，每套 12～15 分钟；**全部坐着或站着完成，不含跳跃和垫上动作**；弹窗按步骤倒数，带运动指示灯；
> - ✅ **计划可视化编辑器**：设置页里新建 / 复制 / 编辑 / 停用 / 删除；内置计划可以直接改，也能一键恢复默认；
> - ✅ **夜间提醒**：21:30 / 22:00 / 22:30 三张深色星空月亮卡片；只在你 DSH 开着时提醒，可预览、可关闭；
> - ✅ 计划存到 `~/.dsh/storages/dsh-clock/plans.json`；改完保存后**下一轮生效，不用重启**。

## 它会怎么提醒你

到点后，DSH 窗口会**自己回到前台**（就算它缩在托盘里），盖上一层半透明"幕布"，
中间弹出圆角卡片。卡片不是只写一个任务名，而是**一步一步带你做**：

```
        ╭────────────────────────────────────
        │      🐣  准备一下！
        │   本组我们选择：踏步走 100 个 + 提踵 30×2 组 哦！
        │               10
        │   10 秒后开始，我们先做「原地踏步」
        │   ● ● ● ● ● ● ● ● ● ● ● ●
        ╰────────────────────────────────────
                       ↓
        ╭────────────────────────────────────
        │ 🚶 踏步 + 提踵 · 踏步走 100 个 + 提踵 30×2 组
        │ 第 1/18 步 · 踏步走 100 个
        │ ● ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○
        │        原地踏步
        │ 抬头挺胸，摆臂，膝盖抬到肚脐高度
        │        100 个
        │ ▓▓░░░░░░░░░░░░░░
        │ 下一项：喝口水
        │ 总剩余 12:55  ▓▓░░░░░░░░░░
        │ [ 我休息好啦 ]（倒计时中灰掉）
        │ （长按这里 3 秒可紧急跳过）
        ╰────────────────────────────────────
```

- **准备 10 秒**：大数字 10 → 1，告诉你"本组选了什么、第一个动作是什么"。
- **动作步骤**：次数型从目标数倒数（100、99、98…）；休息型读秒。
- **运动指示灯**：一排小圆点，已完成的变橙、当前步放大变红。
- **组数徽章**：如"第 1/2 组"、"提踵 30×2 组"。
- **总剩余**：整段休息还剩多少，一直在卡片底部。
- 倒计时没走完，"我休息好啦"是灰的；长按 3 秒可紧急跳过。

## 夜间提醒（21:30 / 22:00 / 22:30）

只要 DSH 还开着（缩到托盘也算），到点会弹一张**深色星空 + 月亮**的卡片，不响系统提示音：

| 时间 | 卡片标题 | 大意 |
| --- | --- | --- |
| 21:30 | 已经九点半了 | 距离该休息还剩一小时，把手里的事收个尾，别玩得太晚 |
| 22:00 | 还有最多半小时 | 夜深了，准备休息；为了健康，别熬得太晚 |
| 22:30 | 十点半啦，真的该睡啦 | 子午流注：子时（23:00～01:00）最需要安静入睡，晚安 🌙 |

- 21:30 先提醒"还剩一小时"，22:00 再收一次，22:30 是最后一句；
- 如果 DSH 是 22:10 才打开的，只补最近一条（22:00），不会连弹三条；同一天不重复；
- 设置里可以关掉，也可以点「预览夜间提醒」先看效果；
- 关掉 DSH 就不会提醒（没有后台服务）；用的是**系统本地时间**。

## 设置页

打开 **设置 → 健康钟**：

- **工作时长**：5～120 分钟，默认 45。改完从**下一轮**开始生效。
- **休息时长**：
  - `跟随计划`（默认）：用抽到的计划自带的 12～15 分钟；
  - 固定 5～30 分钟：下一次休息用这个总时长，**动作次数不变、节奏按比例缩放**。
- **弹窗大小**：100%～200% 滑杆，默认 150%。字、图标、倒计时、进度条一起等比放大；
  屏幕放不下时卡片内部滚动。
- **夜间提醒**：默认开启，21:30 / 22:00 / 22:30 各弹一次；可以关掉，也可以
  「预览夜间提醒」先看效果（预览不占用今晚的正式提醒）。
- **计划库（12 套内置 + 你自己的）**：
  - 点标题展开每一步；「试做」立即开始一次休息；「编辑」直接改动作；
  - 「+ 新建计划」从 5 分钟的模板开始；「复制一份」在现有计划上改；
  - 内置计划可以「停用」（不参与随机）或「恢复默认」；自己建的可以删除；
  - 总时长 5～30 分钟都能存，12～15 分钟最合适；至少保留 1 套启用。
- 设置保存在 `~/.dsh/storages/dsh-clock/settings.json`，计划保存在
  `~/.dsh/storages/dsh-clock/plans.json`，重启 DSH 后继续用。

| 2 | 深蹲 + 侧步 | 12.3 min | 腿臀 / 心肺 |
| 3 | 肩颈 + 金鸡独立 | 12.8 min | 肩颈 / 平衡 |

| 6 | 站姿臀腿 + 椅子核心 | 13.0 min | 臀腿 / 核心 |
| 7 | 办公椅拉伸 | 12.6 min | 肩颈 / 腰背 / 髋 |
| 8 | 原地快走 + 侧步 | 12.0 min | 心肺 / 腿脚 |
| 9 | 椅子操 | 12.2 min | 腿 / 背 / 手臂 |
| 10 | 全身拉伸流 | 12.2 min | 全身柔韧 |
| 11 | 八段锦简化版 | 14.2 min | 全身 / 呼吸 |
| 12 | 呼吸 + 站姿核心 | 12.0 min | 核心 / 呼吸 |

每套都含：10 秒准备、若干动作（含组间休息）、最后拉伸/呼吸收尾。
**全部动作都能坐着或站着完成，不含跳跃和垫上动作**；肩颈绕环已放慢到约 2.5 秒一圈。

在这 12 套之外，你可以在设置页里**新建自己的计划**，也可以把内置的某套改掉或停用。

### 自己加计划 / 改计划（不用改代码）

打开 **设置 → 健康钟 → 计划库**：

- **+ 新建计划**：从一个约 5 分钟的模板开始，加动作、改秒数；
- **编辑**：改名字、表情、概要，以及每一步的动作名 / 次数 / 单位 / 秒数 / 提示 / 组数；
  能加一步、删一步、上下挪；
- **复制一份**：在现有计划基础上改，原计划不动；
- **停用 / 启用**：停用的计划不参与随机抽取，但还留在列表里；
- **恢复默认**：内置计划改坏了，一键变回原样；**恢复全部内置**会清掉你新建和改过的；
- **删除**：只对自己建的生效；内置的请用「停用」。

总时长 **5～30 分钟**都能保存，**12～15 分钟最合适**；保存后下一轮随机抽取就会用到，
**不用重启 DSH**。计划存在 `~/.dsh/storages/dsh-clock/plans.json`。

> 想改内置的"默认值"本身（比如给所有人换一套），才需要改 `lib/plans.js` 并完全重启 DSH；
> 日常自己用，直接在设置页里改就够了。

## 安装、重启与升级

这台机器上**已经装好**了（目录联接 + profile 配置）。

```powershell
node tools/install.js            # 安装或修复（重复执行是安全的）
node tools/install.js --status   # 只看状态
node tools/install.js --uninstall
```

> ⚠️ **改完宿主半边（`lib/index.js`）必须完全退出 DSH 再打开。**
> 只刷新页面会让浏览器显示"健康钟 · 离线"——旧宿主进程里还没有新接口。

### 开发者：想快速测试

1. 把 `lib/index.js` 顶部 `const DEV_MODE = false;` 改成 `true`；
2. 完全退出 DSH 再打开；
3. 工作时长变成 2 分钟、休息 20 秒，设置页仍可打开。

## 现在能做什么 / 还不能做什么

**已经能：**

- 宿主计时：窗口最小化 / 缩到托盘，计时照走；
- 到点把窗口叫回前台：最小化用 Win32 恢复；× 关到托盘用 UI Automation
  **模拟点一下托盘图标**（和手动双击同一条路），让 Electron 自己 `show()/focus()` 并重绘；
- 12 套 12～15 分钟内置计划，引导式弹窗：准备 10 秒、步骤徽章、运动指示灯、次数/秒数倒数、下一项、总剩余；
- 设置页调工作时长 / 休息时长 / 弹窗大小，设置持久化；
- **计划可视化编辑器**：新建、复制、编辑、停用、删除、恢复默认，存到 `plans.json`，保存后下一轮生效；
- **弹窗整体放大**：100%～200%，字、图标、倒计时、进度条一起等比变大；
- **夜间提醒**：21:30 / 22:00 / 22:30，深色星空月亮卡片，只在你 DSH 开着时提醒；
- 计划库展开查看、复制 JSON；
- 浏览器提示音 + 窗口标题闪烁；长按 3 秒紧急跳过；
- 页面刷新不丢进度（状态在宿主里）；彻底重启 DSH 才重新开始。

**还没做：**

- 今日统计 / 连续天数；
- Windows 系统通知 / 置顶小窗（独占全屏游戏可能抢不到焦点）；
- 提示音开关/音量；
- 中英文。

## 它是怎么工作的（大白话）

- **宿主半边 = 值班室**：45 分钟计时、挑计划、到点"拍醒"窗口，提供 `/state` `/settings` `/plans` 等接口；
- **浏览器半边 = 显示屏**：每 2 秒问一次状态，把准备、步骤、倒数、进度画出来；
- **PowerShell 脚本 = 跑腿的**：窗口在托盘里时，用 Win32 + UI Automation 点托盘图标，
  让 Electron 自己把窗口显示出来并重绘。

## 已知限制

- **必须完全重启 DSH** 才能加载新宿主（设置接口）和新客户端。
- 弹窗放大到 200% 时，内容多会**在卡片内部滚动**；小屏幕上会自动收窄。
- 自定义计划允许 5～30 分钟；想完全按计划节奏休息，选「跟随计划」，别用固定休息时长。
- 固定休息时长会缩放动作节奏（次数不变）；想完全按计划节奏选"跟随计划"。
- 动作次数是按时间倒数的**引导**，不会检测你有没有真的做。
- **独占全屏游戏**：Windows 可能拒绝后台进程抢焦点；脚本会恢复窗口、闪任务栏、响提示音，
  实在弹不出来时，下个版本加"置顶小窗 / 系统通知"。
- **DSH 完全退出**：宿主进程没了，计时也停。
- 夜间提醒只在你 **DSH 开着**时生效；DSH 完全退出就没有提醒。它用的是**系统本地时间**，
  系统时间不对会跟着错。
- 夜间提醒到点会尝试把窗口叫到前台（独占全屏游戏可能抢不到焦点）；不响系统提示音，
  卡片本身是安静的。
- 旧浏览器标签页要刷新一次才会加载新客户端。

## 如果没弹出来

1. 看左下角：
   - `健康钟 · 离线` → 宿主没起来 / 旧进程，**完全退出 DSH 再打开**；
   - `健康钟 · 连接中` → 等几秒；一直这样也是没重启。
2. 还是不行：把 `~\.dsh\profiles\desktop\package.json` 里 `dsh.profile.bundles` 是否含
   `dsh-clock`、`node tools/install.js --status` 输出、以及 `%TEMP%\dsh-clock-wake.log` 发我。
