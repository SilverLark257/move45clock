# 🐣 Move45clock · 健康钟

> 一个会催你“起来动一动”的 DSH 小插件。
>
> 作者是一个**完全的新手**，这是第一次用 **DeepSeek Harness** 做 **vibecoding**。  
> 没有团队、没有公司，就是想让久坐的人多站起来两次的小作品。

---

## 你好呀，我是健康钟

你坐在电脑前敲键盘、看屏幕，一坐就是大半天。  
我会在你连续工作后，把 DSH 窗口轻轻叫到前面，弹出一张卡片，带你做一套 **12～15 分钟**的休息计划。

不是冷冰冰的“该休息了”，而是：

> “本组我们选择：踏步走 100 个 + 提踵 30×2 组 哦！”  
> “10 秒后开始，我们先做「原地踏步」。”

然后一步一步陪你做完。

---

## 它会为你做什么

- 🕰️ **45 分钟工作计时**（可调 5～120 分钟）
- 🐣 **到点弹卡片**：窗口最小化、缩到托盘，也会把 DSH 叫回来
- 🧘 **12 套内置计划**：每套 12～15 分钟，全部坐着 / 站着完成，不含跳跃和垫上动作
- 🎬 **一步一步带你做**：10 秒准备、动作名、次数 / 秒数倒数、组间休息、下一项、总剩余
- 🎨 **计划编辑器**：在设置页里新建 / 复制 / 编辑 / 停用 / 删除计划，不用改代码
- 🔍 **弹窗放大**：100%～200%，字、图标、倒计时一起变大（近视友好）
- 🌙 **夜间提醒**：21:30 / 22:00 / 22:30 三张星空月亮卡片，提醒你早点睡
- 🔊 **可选语音**：点「动起来」后，用系统中文语音只报动作名，不读数
- 🔒 **本地运行**：不需要账号，不上传数据，不联网也能用（语音也用系统自带）

## 安装

### 方法一：插件市场（最省事）

1. 打开 DSH；
2. 进入 **设置 → 插件市场**；
3. 搜索 **Move45clock**（或 `dsh-move45clock`）；
4. 点安装；
5. **完全退出 DSH 再打开**（不是点右上角的 ×，是托盘右键退出）。

### 方法二：命令行

```sh
dsh plugin --profile web add dsh-move45clock
```

装完同样**完全退出 DSH 再打开**。

> 第一次装完，左下角会出现一只 🐣，旁边有倒计时。  
> 系统：Windows 10 / 11；DSH 0.2.x。其他系统可能能装，但“把窗口叫回来”是 Windows 专用的。

---

## 第一次使用

1. 打开 **设置 → 健康钟**；
2. 看一眼 **工作时长**（默认 45 分钟）和 **休息时长**（默认跟随计划）；
3. 点 **计划库 → 试做**，先试一套；
4. 10 秒准备页会问你要不要语音：点 **「🔊 动起来（带语音）」**，或者不点，安静开始；
5. 跟着卡片做，做完点 **「开始下一轮」**。

> 小提示：想马上看卡片，点左下角 🐣 →「现在休息一下」。

---

## 几个小按钮

- **我休息好啦**：休息倒计时走完才会亮，点它进入下一轮；
- **长按 3 秒可紧急跳过**：老板突然叫你、或者身体不舒服时用；
- **🔊 动起来（带语音）**：只报动作名，不报 1、2、3；
- **🔇 关掉语音**：运动中随时可以安静；
- **试做**：在设置页的计划库里，立即开始某一套计划。

---

## 设置页有什么

打开 **设置 → 健康钟**：

- **工作时长**：5～120 分钟，默认 45；
- **休息时长**：跟随计划（12～15 分钟），或固定 5～30 分钟；
- **弹窗大小**：100%～200%，默认 150%；
- **夜间提醒**：默认开启，21:30 / 22:00 / 22:30；
- **计划库**：12 套内置 + 你自己的计划；可以新建、复制、编辑、停用、删除、恢复默认。

改完点 **保存设置**；计划改完点 **保存计划**，下一轮生效，不用重启。

### 想自己加一套计划？

设置 → 健康钟 → 计划库 → **+ 新建计划**：

- 可以改名字、表情、概要；
- 每一步可以改动作名、次数、单位、秒数、提示、组数；
- 能加一步、删一步、上下挪；
- 总时长 5～30 分钟都能存，12～15 分钟最合适；
- 保存后下一轮随机抽取就会用到，**不用重启**。

## 夜间提醒

只要 DSH 还开着（缩到托盘也算），到点会弹一张深色星空月亮卡片：

| 时间 | 它会说 |
| --- | --- |
| 21:30 | 已经九点半了，距离该休息还剩一小时，把手里的事收个尾 |
| 22:00 | 还有最多半小时，夜深了，准备洗漱 |
| 22:30 | 十点半啦，子时（23:00～01:00）最该安静入睡，晚安 🌙 |

- 不响系统提示音；
- 22:10 才打开只补最近一条，不会连弹三条；
- 设置里可以关掉，也可以「预览夜间提醒」先看效果。

---

## 语音怎么用

1. 准备页点 **「🔊 动起来（带语音）」**；
2. 它会说：`好，准备开始。` → `开始肩颈绕环动作` → `接下来，开始原地踏步动作`；
3. 休息步骤会说 `接下来：组间休息`；
4. 最后说一句 `这套动作完成啦`；
5. 不读数、不念提示——这是作者试过后改的：读数太快，会跟动作打架。

> 语音用的是电脑自带的中文朗读，不需要下载音频。  
> 没装中文语音时，它可能读得有点怪；可以在 Windows 设置里安装中文语音。  
> 不点「动起来」就没有声音，10 秒后照常开始。

## 常见问题

**Q：到点没弹窗？**  
A：先看左下角是不是「健康钟 · 离线」。是的话，完全退出 DSH 再打开。

**Q：窗口在托盘里，能弹出来吗？**  
A：能。它会模拟点一下任务栏托盘图标，让 DSH 自己回到前台；会短暂打开“隐藏的图标”面板。  
独占全屏游戏可能抢不到焦点，这是 Windows 的限制。

**Q：语音没声音？**  
A：先点一下「动起来」（浏览器要求你先点一下才允许出声）；再检查系统音量；  
如果电脑没装中文语音，会提示“声音可能有点怪”。

**Q：关掉 DSH 还会提醒吗？**  
A：不会。计时和夜间提醒都在 DSH 进程里；DSH 完全退出就停了。

**Q：数据会上传吗？**  
A：不会。没有账号、没有服务器、没有统计；设置和计划只存在这台电脑上。

**Q：动作做不动怎么办？**  
A：以舒服为准，减小幅度或长按跳过；不舒服就停。它只是个提醒，不是医生。
