# 🐣 Move45clock · 健康钟

> 一个会催你“起来动一动”的 DSH 小插件。
>
> 作者是一个**完全的新手**，这是第一次用 **DeepSeek Harness** 做 **vibecoding**。  
> 没有团队、没有公司，就是想让久坐的人多站起来两次的小作品。

## 你好呀，我是健康钟

你坐在电脑前敲键盘、看屏幕，一坐就是大半天。  
我会在你连续工作后，把 DSH 窗口轻轻叫到前面，弹出一张卡片，带你做一套休息计划。  
默认节奏是 **「短短短长」**：多数时候只做 **3～5 分钟**，攒够 3 次短的，再来一次 **12～15 分钟**的长休息——这样更容易坚持。

不是冷冰冰的“该休息了”，而是：

> “本组我们选择：踏步走 100 个 + 提踵 30×2 组 哦！”  
> “10 秒后开始，我们先做「原地踏步」。”

然后一步一步陪你做完。

---

## 它会为你做什么

- 🕰️ **45 分钟工作计时**（可调 5～120 分钟）
- 🐣 **到点弹卡片**：窗口最小化、缩到托盘，也会把 DSH 叫回来
- 🧘 **22 套内置计划**：12 套运动（12～15 分钟）+ 4 套**家务休闲**（擦桌子 / 拖地 / 整理衣服 / 洗衣）+ 6 套**短运动**（3～5 分钟）；运动计划坐着 / 站着完成，不含跳跃和垫上动作
- ⏱️ **你偏爱的计划类**：纯运动 / 运动+家务 / 短短短长运动；选哪种就按哪种来（默认「短短短长」）
- 🎬 **一步一步带你做**：10 秒准备、动作名、次数 / 秒数倒数、组间休息、下一项、总剩余
- 🎨 **计划编辑器**：在设置页里新建 / 复制 / 编辑 / 停用 / 删除计划，不用改代码；内置计划也能删，删了可以在「已删除的内置计划」里恢复
- 🔍 **弹窗放大**：100%～200%，字、图标、倒计时一起变大（近视友好）
- 📊 **今日统计**：今天休息了几次、多少分钟；连续天数；最近 7 天的小柱子
- 📌 **到点置顶小窗**：屏幕右下角弹一条，不抢键盘焦点，25 秒自动消失（独占全屏游戏除外）
- 🔄 **重启接续**：同一天内退出 DSH 再打开，计时接着上次走，不用重新等 45 分钟
- 🌙 **夜间提醒**：21:30 / 22:00 / 22:30 三张星空月亮卡片，提醒你早点睡
- 🔊 **可选语音**：点「动起来」后，用系统中文语音只报动作名，不读数
- 🔒 **本地运行**：不需要账号，不上传数据，不联网也能用（语音也用系统自带）

## 安装

### 在 DSH 插件市场安装（推荐）

1. 打开 DSH；
2. 进入 **设置 → 插件市场**；
3. 搜索 **Move45clock**；
4. 点安装；
5. **完全退出 DSH 再打开**（不是点右上角的 ×，是托盘右键退出）。

> 插件市场会直接从 GitHub 安装，**不需要 npm**。  
> 如果暂时搜不到，说明目录还在审核中，过一两天再来搜。

> 第一次装完，左下角会出现一只 🐣，旁边有倒计时。  
> 系统：Windows 10 / 11；DSH 0.2.x。其他系统可能能装，但“把窗口叫回来”是 Windows 专用的。

## 第一次使用

1. 打开 **设置 → 健康钟**；
2. 选一下 **你偏爱的计划类**（默认「短短短长运动计划」）；
3. 看一眼 **工作时长**（默认 45 分钟）和 **休息时长**（默认跟随计划）；
4. 点 **计划库 → 试做**，先试一套；
4. 10 秒准备页会问你要不要语音：点 **「🔊 动起来（带语音）」**，或者不点，安静开始；
5. 跟着卡片做，做完点 **「开始下一轮」**。

> 小提示：想马上看卡片，点左下角 🐣 →「现在休息一下」。

---

## 几个小按钮

- **我休息好啦**：休息倒计时走完才会亮，点它进入下一轮；
- **长按 3 秒可紧急跳过**：老板突然叫你、或者身体不舒服时用；
- **🔊 动起来（带语音）**：只报动作名，不报 1、2、3；
- **🔇 关掉语音**：运动中随时可以安静；
- **试做**：在设置页的计划库里，立即开始某一套计划。

---

## 设置页有什么

打开 **设置 → 健康钟**：

- **工作时长**：5～120 分钟，默认 45；
- **你偏爱的计划类**：三选一，默认「短短短长运动计划」；
  - 纯运动计划：只用 12 套运动（12～15 分钟）；
  - 运动+家务计划：12 套运动 + 4 套家务，随机；
  - 短短短长运动计划：3 次 3～5 分钟的短运动 + 1 次 12～15 分钟的长运动，循环；
- **休息时长**：选「短短短长」时自动跟随计划（短 3～5 分钟 / 长 12～15 分钟）；
  其它两种可以跟随计划（12～15 分钟）或固定 5～30 分钟；
- **弹窗大小**：100%～200%，默认 150%；
- **置顶小窗**：默认开启；到点在屏幕右下角弹一条，不抢键盘焦点，25 秒自动关；
  旁边有「预览小窗」，不用等 45 分钟就能看效果；
- **夜间提醒**：默认开启，21:30 / 22:00 / 22:30；
- **计划库**：22 套内置（12 套运动 + 4 套家务休闲 + 6 套短运动）+ 你自己的计划；可以新建、复制、编辑、停用、删除、恢复默认。
  每套右侧都有「删除」；删掉的内置计划会收进下方「已删除的内置计划」，随时可以恢复。

> 点左下角 🐣 打开面板，还能看到**今天完成几次、连续几天、最近 7 天**。

改完点 **保存设置**；计划改完点 **保存计划**，下一轮生效，不用重启。

### 想自己加一套计划？

设置 → 健康钟 → 计划库 → **+ 新建计划**：

- 可以改名字、表情、概要；
- 每一步可以改动作名、次数、单位、秒数、提示、组数；
- 能加一步、删一步、上下挪；
- 总时长 5～30 分钟都能存（短运动计划是 3～5 分钟），12～15 分钟最合适；
- 保存后下一轮随机抽取就会用到，**不用重启**。

### 临时不想看到某套计划？

- **停用**：不参与随机抽取，但还留在列表里；
- **删除**：从列表和随机抽取里收起来。内置计划删掉后，能在计划库下方的
  「已删除的内置计划」里点「恢复」找回来；自己新建的计划删了就真没了。
- 至少要留 1 套计划，最后一套删不掉。

## 4 套「家务休闲」

不想做操的时候，可以把休息换成顺手能做完的轻家务：

| 计划 | 时长 | 大概做什么 |
| --- | --- | --- |
| 🧽 擦桌子 | 12.0 分钟 | 餐桌 → 书桌 → 窗台/柜面 → 椅子，顺手活动肩背 |
| 🧹 拖地 | 12.6 分钟 | 客厅 → 卧室 → 书房/走廊 → 厨房 → 卫生间，拖完拉伸腰背 |
| 👕 整理衣服 | 12.0 分钟 | 分类 → 叠上衣/裤子 → 挂外套 → 收进柜子 |
| 🧺 洗衣 | 12.6 分钟 | 收脏衣服 → 分类 → 开机 → 手洗小件 → 晾衣服 |

> 这 4 套会和运动计划一起随机出现；不想要就按上面的方法删掉或停用。
> 家务计划会走动、弯腰，**以舒服为准，累了就慢一点**，不用全部做完。

## 6 套「短运动」（3～5 分钟）

「短短短长」用得上的小锻炼。动作都很简单，站起来在桌边就能做完：

| 计划 | 时长 | 大概做什么 |
| --- | --- | --- |
| 🧘 肩颈松一松 | 约 3.0 分钟 | 慢速肩颈绕环 → 扩胸 → 手臂画圈，最后拉伸 |
| 🦵 椅子深蹲 | 约 3.5 分钟 | 扶椅背慢慢坐下、起立，活动腿臀 |
| 🚶 原地踏步 | 约 3.0 分钟 | 原地踏步 + 摆臂，把心跳带起来一点 |
| 🙆 站姿拉伸 | 约 3.0 分钟 | 肩、背、髋、小腿各拉一下 |
| 💪 墙边推撑 | 约 4.0 分钟 | 扶墙做半程推撑，练手臂和胸背 |
| 👟 走廊快走 | 约 5.0 分钟 | 在走廊或屋里快走一圈，最后拉伸 |

> 短运动只在「你偏爱的计划类 = 短短短长运动计划」时才会被抽到；
> 想换成更长的休息，就在设置里换计划类，或者把短运动计划删掉/停用。

---

## 「短短短长」是怎么运作的

- 工作计时（默认 45 分钟，你设成 40 也行）结束 → **短休息**（3～5 分钟的小锻炼）；
- 再工作一轮 → 又来一次短休息；
- **第 3 次短休息之后**，下一次休息变成**长休息**（12～15 分钟，从 12 套运动里抽）；
- 长休息结束，周期从头开始：短 → 短 → 短 → 长 → 短 → …
- 休息卡片准备页会显示「短短短长 · 第 N/4 次 · 短休息 / 长休息」，左下角面板也能看到下一次是短还是长；
- 长按紧急跳过也算“这一次休息已经发生”，节奏不会乱。

> 想改节奏不用改代码：设置里换「你偏爱的计划类」，或者直接把不想要的计划删掉/停用。

## 夜间提醒

只要 DSH 还开着（缩到托盘也算），到点会弹一张深色星空月亮卡片：

| 时间 | 它会说 |
| --- | --- |
| 21:30 | 已经九点半了，距离该休息还剩一小时，把手里的事收个尾 |
| 22:00 | 还有最多半小时，夜深了，准备洗漱 |
| 22:30 | 十点半啦，子时（23:00～01:00）最该安静入睡，晚安 🌙 |

- 不响系统提示音；
- 22:10 才打开只补最近一条，不会连弹三条；
- 设置里可以关掉，也可以「预览夜间提醒」先看效果。

---

## 语音怎么用

1. 准备页点 **「🔊 动起来（带语音）」**；
2. 它会说：`好，准备开始。` → `开始肩颈绕环动作` → `接下来，开始原地踏步动作`；
3. 休息步骤会说 `接下来：组间休息`；
4. 最后说一句 `这套动作完成啦`；
5. 不读数、不念提示——这是作者试过后改的：读数太快，会跟动作打架。

> 语音用的是电脑自带的中文朗读，不需要下载音频。  
> 没装中文语音时，它可能读得有点怪；可以在 Windows 设置里安装中文语音。  
> 不点「动起来」就没有声音，10 秒后照常开始。

## 常见问题

**Q：到点没弹窗？**  
A：先看左下角是不是「健康钟 · 离线」。是的话，完全退出 DSH 再打开。

**Q：窗口在托盘里，能弹出来吗？**  
A：能。它会模拟点一下任务栏托盘图标，让 DSH 自己回到前台；会短暂打开“隐藏的图标”面板。  
独占全屏游戏可能抢不到焦点，这是 Windows 的限制。

**Q：全屏游戏能看到提醒吗？**  
A：到点会在屏幕右下角弹一条**置顶小窗**，不抢键盘焦点，25 秒自动消失。  
无边框全屏和普通窗口能看到；独占全屏（那种黑屏切换的）Windows 可能还是盖住，这是系统限制。  
不想要可以在设置里关掉。

**Q：统计会算“长按跳过”吗？**  
A：不会。只有休息倒计时真的走完才记一次；跳过不算，免得刷数字。

**Q：某套计划我不想要，能删掉吗？**  
A：能。设置 → 健康钟 → 计划库，点那套右边的「删除」。  
内置计划删掉后会收进「已删除的内置计划」，以后想用还能恢复；自己建的计划删了就没了。  
只是想暂时不随机到它，点「停用」就行，列表里还留着。

**Q：「短短短长」是怎么算的？**  
A：每一轮工作结束都算一次休息。第 1、2、3 次是 3～5 分钟的短休息，第 4 次自动变成
12～15 分钟的长休息，然后重新数。长按跳过也算发生过一次，只是不计入统计。
想换成别的节奏，就在设置里的「你偏爱的计划类」切换。

**Q：装了 Codex UI 的玻璃主题，弹窗会变透明吗？**  
A：以前的版本会（Codex UI 会把所有弹窗改成半透明玻璃）。v1.7.0 起健康钟给自己加了防护，
弹窗会保持原本的奶油色不透明卡片；如果你确实更喜欢玻璃效果，那是 Codex UI 自己的事，
健康钟这边不会再被它带透明。

**Q：语音没声音？**  
A：先点一下「动起来」（浏览器要求你先点一下才允许出声）；再检查系统音量；  
如果电脑没装中文语音，会提示“声音可能有点怪”。

**Q：关掉 DSH 还会提醒吗？**  
A：不会。计时和夜间提醒都在 DSH 进程里；DSH 完全退出就停了。

**Q：退出 DSH 再打开，计时会清零吗？**  
A：同一天内不会：工作和休息的剩余时间会接着上次走；过了 0 点（新的一天）才重新开始。  
如果关着的时候已经到点，打开后会直接进入休息。

**Q：数据会上传吗？**  
A：不会。没有账号、没有服务器；设置、计划、统计和夜间记录都只存在这台电脑上。

**Q：动作做不动怎么办？**  
A：以舒服为准，减小幅度或长按跳过；不舒服就停。它只是个提醒，不是医生。
