# 健康钟 · dsh-clock

> 🐣 一个会催你"起来动一动"的 DSH 小插件。

你坐在电脑前敲键盘、看屏幕，一坐就是大半天。健康钟会在你连续工作 **45 分钟**后，
把 DSH 窗口叫到最前面，弹出一张卡通休息卡片，随机派一个休息计划，并且"按住你"
休息 **10～15 分钟**。休息结束后计时归零，开始下一轮。

> 📌 **当前状态：v1.0.0（2026-10-18）**
> - ✅ 第一版完成并验收通过：**最小化 / × 关闭到托盘，到点都能自动弹出彩色卡片**；
> - ✅ 正式参数：工作 45 分钟，休息 10～15 分钟（13 个计划随机抽）；
> - ⬜ 宿主改了参数，**下一次完全重启 DSH 后生效**（重启前仍是 2 分钟测试模式）；
> - 🔁 下一轮迭代方向见 [CURRENT_STATE.md](CURRENT_STATE.md) 的"下一轮迭代候选"。

## 它会怎么提醒你

到点后，DSH 窗口会**自己回到前台**（就算它缩在托盘里），盖上一层半透明"幕布"，
中间弹出圆角卡片：

```
        ╭────────────────────────────────────
        │
        │   🐣  起来动一动！
        │
        │   🦵  深蹲
        │
        │        ⏰  09:58
        │   ▓▓▓▓▓▓▓▓▓▓░░░░░░░
        │
        │   [ 我休息好啦 ]   ← 休息中永远是灰的
        │
        │   （长按这里 3 秒可紧急跳过）
        │
        ╰────────────────────────────────────
```

- 工作 45 分钟 → 弹窗 → 休息 10～15 分钟（按抽到的计划定）。
- 每次随机换一个计划：深蹲、踮脚、金鸡独立、开合跳、扩胸、肩颈绕环……
- 休息倒计时没走完，按钮是灰的、点不动；实在有急事，可以"长按 3 秒"紧急跳过。
- 倒计时结束，卡片变成 🎉，点"开始下一轮"，弹窗关闭，重新开始。
- 左下角常驻入口：🐣 + 剩余时间；**点一下**打开详情面板。

### 左下角详情面板

```
🐣 健康钟                    ×
       41:32
▓▓▓▓▓▓▓░░░░░░░░
────────────────────
状态        工作中
下次提醒    18:25
今天完成    2 次
────────────────────
[现在休息一下] [重新计时]
────────────────────
📊 统计与连续天数     即将上线
🧩 自定义休息计划     即将上线
🔔 提示音与音量       即将上线
```

- **现在休息一下**：不用等 45 分钟，立刻来一轮休息（想马上看效果就用它）。
- **重新计时**：清零，重新开始 45 分钟。
- 底部的"即将上线"是给迭代 2 预留的入口，点一下会提示"还在开发中"。

## 安装、重启与升级

这台机器上**已经装好**了（目录联接 + profile 配置）。一般不需要再装。

需要重装 / 修复 / 卸载时，在项目文件夹里执行：

```powershell
node tools/install.js            # 安装或修复（重复执行是安全的）
node tools/install.js --status   # 只看状态，不改任何东西
node tools/install.js --uninstall
```

> ⚠️ **改完宿主半边（`lib/index.js`）必须完全退出 DSH 再打开。**
> 只刷新页面的话，浏览器半边会显示"健康钟 · 离线"——因为旧宿主进程里还没有新接口。
> 这是预期现象，不是插件坏了。

## 怎么用

- 打开 DSH → 左下角出现 🐣 和倒计时 → 正常干活；
- 45 分钟后窗口自己回到前台，弹卡片；
- 按卡片上的任务动一动，等倒计时走完 → 点"开始下一轮"；
- 想提前休息 / 看还剩多久 / 重新计时 → 点左下角 🐣。

### 开发者：想快速测试

1. 把 `lib/index.js` 顶部 `const DEV_MODE = false;` 改成 `true`；
2. 完全退出 DSH 再打开；
3. 工作变成 2 分钟、休息 20 秒，面板里会多一个「测试提醒」按钮（只叫醒窗口，不强制休息）。

## 现在能做什么 / 还不能做什么

**已经能：**

- 宿主进程计时：窗口最小化 / 缩到托盘，计时照走；
- 到点自动把 DSH 窗口叫回前台：
  - 最小化 → Win32 恢复；
  - × 关到托盘 → 用 UI Automation **模拟点一下托盘图标**（和手动双击同一条路），
    让 Electron 自己 `show()/focus()`，网页真正重绘；
- 13 个休息计划随机抽（不连续重复），每个自带 10～15 分钟休息时长；
- 大倒计时、进度条、最后 10 秒变红心跳；
- 浏览器提示音 + 窗口标题闪烁；
- 长按 3 秒紧急跳过；
- 页面刷新不丢进度（状态在宿主里）；彻底重启 DSH 才重新开始；
- 多窗口共享同一份状态；
- 左下角详情面板 + 后续功能预留入口。

**还没做：**

- 中英文切换（先中文）；
- 设置页（工作/休息时长、计划开关、提示音）；
- 今日统计 / 连续天数、自定义休息计划（面板里是占位入口）；
- Windows 系统通知 / 置顶小窗（独占全屏游戏可能抢不到焦点）；
- 多窗口"只让一个窗口弹卡片"。

## 它是怎么工作的（大白话）

- **宿主半边 = 值班室**：盯着表，到点先"拍醒" DSH 窗口，再把状态改成"该休息了"；
- **浏览器半边 = 显示屏**：每 2 秒问一次值班室"现在什么状态"，把卡片和倒计时画出来；
- **PowerShell 脚本 = 跑腿的**：去 Windows 那里把 DSH 窗口从托盘里拽出来、放最前面、
  闪任务栏、响一声。窗口是点 × 藏进托盘的，它会**模拟你点一下托盘图标**——
  和手动双击托盘是同一条路（Electron 自己的 `window.show()`），网页才会真正重绘。

窗口隐藏时，显示屏可以打瞌睡，但值班室不会——这就是"托盘里也能弹窗"的关键。

## 已知限制

- **独占全屏游戏**：Windows 可能拒绝后台进程抢焦点。脚本仍会恢复窗口、闪任务栏、响系统提示音；
  实在弹不出来时，下一版加"置顶小窗"或 Windows 系统通知。
- **托盘图标依赖**：UIA 点托盘需要任务栏和 DSH 托盘图标存在；找不到时回退 Win32
  （可能还是旧画面）。每次唤醒可能让"隐藏的图标"面板闪一下，正常。
- **DSH 完全退出**：宿主进程没了，计时也停（"只要 DSH 没关闭"的边界就在这里）。
- **提示音**：浏览器自动播放策略要求先和页面交互过；没点过页面时可能只有系统"叮"一声。
- **旧浏览器标签页**：需要刷新一次才会加载新客户端。
- 计时只在宿主内存里：**彻底重启 DSH 会算新一轮**；刷新页面不丢。

## 如果没弹出来

1. 先看左下角文字：
   - `健康钟 · 离线` → 宿主没起来 / 旧进程，**完全退出 DSH 再打开**；
   - `健康钟 · 连接中` → 等几秒；一直这样也是没重启。
2. 已经重启还是没弹：把 `~\.dsh\profiles\desktop\package.json` 里
   `dsh.profile.bundles` 是否包含 `dsh-clock`、`node tools/install.js --status` 的输出，
   以及 `%TEMP%\dsh-clock-wake.log` 一起发我（脚本每一步都记了日志）。
