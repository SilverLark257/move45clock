# 健康钟 · dsh-clock

> 🐣 一个会催你"起来动一动"的 DSH 小插件。

你坐在电脑前敲键盘、看屏幕，一坐就是大半天。健康钟会在你连续工作后，
把 DSH 窗口叫到最前面，弹出一张卡通卡片，带你做一套 **12～15 分钟**的休息计划：
10 秒准备 → 按步骤倒数 → 拉伸收尾。做完计时归零，进入下一轮。

> 📌 **当前状态：v1.1.0（2026-10-18，迭代 2）**
> - ✅ 设置页：**工作时长**（5～120 分钟）和**休息时长**（跟随计划 / 固定 5～30 分钟）都能调；
> - ✅ **12 套详细计划**，每套 12～15 分钟，弹窗按步骤倒数，带运动指示灯；
> - ✅ 计划库在设置页可展开查看、复制 JSON；修改入口是 `lib/plans.js`；
> - ⬜ 宿主和客户端都改了，**下一次完全重启 DSH 后生效**。

## 它会怎么提醒你

到点后，DSH 窗口会**自己回到前台**（就算它缩在托盘里），盖上一层半透明"幕布"，
中间弹出圆角卡片。卡片不是只写一个任务名，而是**一步一步带你做**：

```
        ╭────────────────────────────────────
        │      🐣  准备一下！
        │   本组我们选择：踏步走 100 个 + 提踵 30×2 组 哦！
        │               10
        │   10 秒后开始，我们先做「原地踏步」
        │   ● ● ● ● ● ● ● ● ● ● ● ●
        ╰────────────────────────────────────
                       ↓
        ╭────────────────────────────────────
        │ 🚶 踏步 + 提踵 · 踏步走 100 个 + 提踵 30×2 组
        │ 第 1/18 步 · 踏步走 100 个
        │ ● ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○ ○
        │        原地踏步
        │ 抬头挺胸，摆臂，膝盖抬到肚脐高度
        │        100 个
        │ ▓▓░░░░░░░░░░░░░░
        │ 下一项：喝口水
        │ 总剩余 12:55  ▓▓░░░░░░░░░░
        │ [ 我休息好啦 ]（倒计时中灰掉）
        │ （长按这里 3 秒可紧急跳过）
        ╰────────────────────────────────────
```

- **准备 10 秒**：大数字 10 → 1，告诉你"本组选了什么、第一个动作是什么"。
- **动作步骤**：次数型从目标数倒数（100、99、98…）；休息型读秒。
- **运动指示灯**：一排小圆点，已完成的变橙、当前步放大变红。
- **组数徽章**：如"第 1/2 组"、"提踵 30×2 组"。
- **总剩余**：整段休息还剩多少，一直在卡片底部。
- 倒计时没走完，"我休息好啦"是灰的；长按 3 秒可紧急跳过。

## 设置页

打开 **设置 → 健康钟**：

- **工作时长**：5～120 分钟，默认 45。改完从**下一轮**开始生效。
- **休息时长**：
  - `跟随计划`（默认）：用抽到的计划自带的 12～15 分钟；
  - 固定 5～30 分钟：下一次休息用这个总时长，**动作次数不变、节奏按比例缩放**。
- **计划库（12 套）**：点标题展开每一步；每套右侧「试做」可立即开始一次休息；
  「复制计划 JSON」备份/分享。
- 设置保存在 `~/.dsh/storages/dsh-clock/settings.json`，重启 DSH 后继续用。

## 现在能做什么 / 还不能做什么

**已经能：**

- 宿主计时：窗口最小化 / 缩到托盘，计时照走；
- 到点把窗口叫回前台：最小化用 Win32 恢复；× 关到托盘用 UI Automation
  **模拟点一下托盘图标**（和手动双击同一条路），让 Electron 自己 `show()/focus()` 并重绘；
- 12 套 12～15 分钟计划，引导式弹窗：准备 10 秒、步骤徽章、运动指示灯、次数/秒数倒数、下一项、总剩余；
- 设置页调工作时长 / 休息时长，设置持久化；
- 计划库展开查看、复制 JSON；
- 浏览器提示音 + 窗口标题闪烁；长按 3 秒紧急跳过；
- 页面刷新不丢进度（状态在宿主里）；彻底重启 DSH 才重新开始。

**还没做：**

- 计划可视化编辑器（要在设置页里增删改，不动代码）；
- 今日统计 / 连续天数；
- Windows 系统通知 / 置顶小窗（独占全屏游戏可能抢不到焦点）；
- 提示音开关/音量；
- 中英文。

## 它是怎么工作的（大白话）

- **宿主半边 = 值班室**：45 分钟计时、挑计划、到点"拍醒"窗口，提供 `/state` `/settings` `/plans` 等接口；
- **浏览器半边 = 显示屏**：每 2 秒问一次状态，把准备、步骤、倒数、进度画出来；
- **PowerShell 脚本 = 跑腿的**：窗口在托盘里时，用 Win32 + UI Automation 点托盘图标，
  让 Electron 自己把窗口显示出来并重绘。

## 已知限制

- **必须完全重启 DSH** 才能加载新宿主（设置接口）和新客户端。
- 固定休息时长会缩放动作节奏（次数不变）；想完全按计划节奏选"跟随计划"。
- 动作次数是按时间倒数的**引导**，不会检测你有没有真的做。
- **独占全屏游戏**：Windows 可能拒绝后台进程抢焦点；脚本会恢复窗口、闪任务栏、响提示音，
  实在弹不出来时，下个版本加"置顶小窗 / 系统通知"。
- **DSH 完全退出**：宿主进程没了，计时也停。
- 旧浏览器标签页要刷新一次才会加载新客户端。

## 如果没弹出来

1. 看左下角：
   - `健康钟 · 离线` → 宿主没起来 / 旧进程，**完全退出 DSH 再打开**；
   - `健康钟 · 连接中` → 等几秒；一直这样也是没重启。
2. 还是不行：把 `~\.dsh\profiles\desktop\package.json` 里 `dsh.profile.bundles` 是否含
   `dsh-clock`、`node tools/install.js --status` 输出、以及 `%TEMP%\dsh-clock-wake.log` 发我。
