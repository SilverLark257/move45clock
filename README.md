# 健康钟 · dsh-clock

> 🐣 一个会催你"起来动一动"的 DSH 小插件。

你坐在电脑前敲键盘、看屏幕，一坐就是大半天。健康钟会在你连续工作后，
在 DSH 界面最上面弹出一个卡通小窗口，随机派给你一个休息计划（锻炼任务 + 倒计时），
并且"按住你"休息一会儿。休息结束后计时归零，开始下一轮。

> 📌 **当前状态（2026-10-18）**
> - ✅ 插件代码已写好，并已装进 DSH 的 `desktop` profile；
> - ✅ 已实测注册成功：`shell.overlay`（弹窗）和 `sidebar.footer.action`（左下角）里都有它；
> - 🧪 **现在跑的是测试模式：工作 2 分钟、休息 20 秒**（为了不用等 45 分钟就能验收）；
> - ⬜ 还差：你完全重启一次 DSH 亲眼验收 → 通过后我把参数改回 45 分钟正式版；
> - 📦 本地 Git 仓库已建好（`main` 分支，含首次提交），推送到远程的方法见文末。

## 它会怎么提醒你

到点后，界面会盖上一层半透明"幕布"，中间弹出一张圆角大卡片：

```
        ╭────────────────────────────────────
        │
        │   🐣  起来动一动！
        │
        │   🦵  深蹲
        │
        │        ⏰  09:58
        │   ▓▓▓▓▓▓▓▓▓▓░░░░░░░
        │
        │   [ 我休息好啦 ]   ← 休息中永远是灰的
        │
        │   （长按这里 3 秒可紧急跳过）
        │
        ╰────────────────────────────────────
```

- **正式模式**：工作 45 分钟 → 弹窗 → 休息 10～15 分钟（13 个休息计划随机抽，时长按计划定）。
- **测试模式（现在）**：工作 2 分钟 → 弹窗 → 休息 20 秒。
- 每次随机换一个计划：深蹲、踮脚、金鸡独立、开合跳、扩胸、肩颈绕环……
- 休息倒计时没走完，按钮是灰的、点不动；实在有急事，可以"长按 3 秒"紧急跳过。
- 倒计时结束，卡片变成 🎉，点"开始下一轮"，弹窗关闭，重新开始。
- 左下角常驻一个小入口：🐣 + 剩余时间，让你随时知道它还在上班。

## 安装、卸载与验收

这台机器上**已经装好**了（目录联接 + profile 配置）。一般不需要再装。

需要重装 / 修复 / 卸载时，在项目文件夹里执行：

```powershell
node tools/install.js            # 安装或修复（重复执行是安全的）
node tools/install.js --status   # 只看状态，不改任何东西
node tools/install.js --uninstall
```

装完、或改过 `lib/index.js` 之后，必须**完全退出 DSH 再打开**：

- 宿主半边（`lib/index.js`）只在 DSH 启动时加载，改它必须重启；
- 浏览器半边（`lib/client.js`）刷新页面就能更新，改它刷新即可。

### 验收步骤（测试模式）

1. 完全退出 DSH，再打开；
2. 看左下角：出现 🐣 和"健康钟 mm:ss"；
3. 等 2 分钟：全屏休息卡片弹出（之前点过页面的话会有提示音，窗口标题也会闪）；
4. 等 20 秒：卡片变成 🎉；
5. 点"开始下一轮"：倒计时归零，重新开始。

> 如果 2 分钟后没反应：先把 `~\.dsh\profiles\desktop\package.json` 里 `dsh.profile.bundles`
> 是否包含 `dsh-clock`、以及 `node tools/install.js --status` 的输出发我。

## 现在能做什么 / 还不能做什么

**已经能：**

- 自动开始计时，到点自动弹窗；
- 13 个休息计划随机抽（不连续重复），每个自带 10～15 分钟休息时长；
- 大倒计时、进度条、最后 10 秒变红心跳；
- 提示音 + 窗口标题闪烁（把切走的你叫回来）；
- 长按 3 秒紧急跳过；
- 刷新页面不丢计时；彻底重启 DSH 算新一轮；
- 左下角常驻倒计时。

**还没做：**

- 中英文切换（先中文，ADR-008 欠着）；
- 自定义休息计划；
- 多窗口互斥（同时开两个 DSH 窗口会各跑一个计时器）；
- Windows 系统通知、任务栏原生闪烁（插件拿不到 Electron 原生能力，目前只改窗口标题）；
- 设置界面（改时长要改代码常量）。

## 已知限制（第一版）

- 弹窗只能盖住 **DSH 自己的窗口**：DSH 最小化、或你在别的软件全屏时看不见；
  提示音和窗口标题闪烁负责把你叫回来。
- 网页层面无法真正"锁死"你：你永远可以关掉 DSH；我们做的是"不鼓励关闭 + 3 秒后门"。
- 电脑睡眠时间会被算进工作时长：醒来可能立刻弹窗（这是你第 2 轮拍板的）。
- 计时只在前端：**关掉 DSH 窗口，计时就停了**（以后要"关窗也计时"得升级到宿主侧，见 TBD-1）。
- 还没做多窗口互斥：两个窗口会各弹各的，还会互相覆盖本地状态。
