# 健康钟 · dsh-clock

> 🐣 一个会催你"起来动一动"的 DSH 小插件。

你坐在电脑前敲键盘、看屏幕，一坐就是大半天。健康钟会在你连续工作后，
在 DSH 界面最上面弹出一个卡通小窗口，随机派给你一个休息计划（锻炼任务 + 倒计时），
并且"按住你"休息一会儿。休息结束后计时归零，开始下一轮。

> 📌 **当前状态（2026-10-18 第 4 轮）**
> - ✅ 计时搬到了**宿主进程**：DSH 缩在托盘 / 最小化时，到点也会把窗口叫到前台；
> - ✅ 左下角 🐣 点开有**详情面板**，并预留了统计、自定义计划、提示音等入口；
> - 🧪 仍是**测试模式：工作 2 分钟、休息 20 秒**；
> - ⬜ 还差：你完全重启 DSH 亲眼验收 → 通过后我把参数改回 45 分钟正式版。

## 它会怎么提醒你

到点后，DSH 窗口会**自己弹到最前面**（就算它原来缩在托盘里），盖上一层半透明"幕布"，
中间弹出圆角卡片：

```
        ╭────────────────────────────────────
        │
        │   🐣  起来动一动！
        │
        │   🦵  深蹲
        │
        │        ⏰  09:58
        │   ▓▓▓▓▓▓▓▓▓▓░░░░░░░
        │
        │   [ 我休息好啦 ]   ← 休息中永远是灰的
        │
        │   （长按这里 3 秒可紧急跳过）
        │
        ╰────────────────────────────────────
```

- **正式模式**：工作 45 分钟 → 弹窗 → 休息 10～15 分钟（13 个休息计划随机抽）。
- **测试模式（现在）**：工作 2 分钟 → 弹窗 → 休息 20 秒。
- 每次随机换一个计划：深蹲、踮脚、金鸡独立、开合跳、扩胸、肩颈绕环……
- 休息倒计时没走完，按钮是灰的、点不动；实在有急事，可以"长按 3 秒"紧急跳过。
- 倒计时结束，卡片变成 🎉，点"开始下一轮"，弹窗关闭，重新开始。
- 左下角常驻入口：🐣 + 剩余时间；**点一下**打开详情面板。

### 左下角详情面板

```
🐣 健康钟                    ×
       41:32
▓▓▓▓▓▓▓░░░░░░░░
────────────────────
状态        工作中
下次提醒    18:25
今天完成    2 次
────────────────────
[现在休息一下] [重新计时]
────────────────────
📊 统计与连续天数     即将上线
🧩 自定义休息计划     即将上线
🔔 提示音与音量       即将上线
```

测试模式下还多一个 **「测试提醒」** 按钮：点一下立刻把 DSH 窗口叫到前台，
不用等 2 分钟（就是用来验收"叫醒窗口"这条链路的）。

## 安装、重启与验收

这台机器上**已经装好**了（目录联接 + profile 配置）。一般不需要再装。

需要重装 / 修复 / 卸载时，在项目文件夹里执行：

```powershell
node tools/install.js            # 安装或修复（重复执行是安全的）
node tools/install.js --status   # 只看状态，不改任何东西
node tools/install.js --uninstall
```

> ⚠️ **改完宿主半边（`lib/index.js`）必须完全退出 DSH 再打开。**
> 只刷新页面的话，浏览器半边会显示"健康钟 · 离线"——因为旧宿主进程里还没有新接口。
> 这是预期现象，不是插件坏了。

### 验收步骤（测试模式）

1. **完全退出 DSH**（托盘图标右键 → 退出，不是关窗口）；
2. 重新打开 DSH，左下角应出现 🐣 和倒计时；
3. **最小化**和**× 关闭到托盘**两种都试，或切去别的窗口 / 游戏；
4. 等 2 分钟：DSH 窗口应**自己弹到最前**，显示休息卡片，并响一声；
5. 等 20 秒：卡片变 🎉；
6. 点"开始下一轮"：倒计时归零，重新开始；
7. 点左下角 🐣：详情面板能打开，"测试提醒"按钮能把窗口叫到前台。

### 如果没弹出来

1. 先看左下角文字：
   - `健康钟 · 离线` → 宿主还没重启 / 路由没起来，**完全退出 DSH 再打开**；
   - `健康钟 · 连接中` → 等几秒；一直这样也是没重启。
2. 已经重启还是没弹：把 `~\.dsh\profiles\desktop\package.json` 里
   `dsh.profile.bundles` 是否包含 `dsh-clock`、以及 `node tools/install.js --status`
   的输出发我。

## 现在能做什么 / 还不能做什么

**已经能：**

- 计时在宿主进程：窗口最小化 / 缩到托盘，计时照走；
- 到点自动把 DSH 窗口叫到前台（Win32 恢复 + 单实例唤醒 + 闪任务栏 + 系统提示音）——
  **最小化、× 关闭到托盘两种状态都行**；
- 13 个休息计划随机抽（不连续重复），每个自带 10～15 分钟休息时长；
- 大倒计时、进度条、最后 10 秒变红心跳；
- 浏览器提示音 + 窗口标题闪烁；
- 长按 3 秒紧急跳过；
- 页面刷新不丢进度（状态在宿主里）；彻底重启 DSH 才重新开始；
- 多窗口共享同一份状态（不再各弹各的）；
- 左下角详情面板 + 后续功能预留入口。

**还没做：**

- 中英文切换（先中文）；
- 自定义休息计划、统计报表、提示音设置（面板里是占位入口）；
- Windows 系统通知 / 置顶小窗（独占全屏游戏可能抢不到焦点，见"已知限制"）；
- 设置界面（改时长要改代码常量）。

## 它是怎么工作的（大白话）

- **宿主半边 = 值班室**：盯着表，到点先"拍醒" DSH 窗口，再把状态改成"该休息了"；
- **浏览器半边 = 显示屏**：每 2 秒问一次值班室"现在什么状态"，把卡片和倒计时画出来；
- **PowerShell 脚本 = 跑腿的**：去 Windows 那里把 DSH 窗口从托盘里拽出来、放最前面、
  闪任务栏、响一声。

窗口隐藏时，显示屏可以打瞌睡，但值班室不会——这就是这次修好"托盘里不弹窗"的关键。

## 已知限制（第一版）

- **独占全屏游戏可能抢不到焦点**：Windows 会拒绝后台进程抢前台。脚本仍会恢复窗口、
  闪任务栏、响系统提示音；实在弹不出来时，下一版加"置顶小窗"或系统通知。
- **浏览器里打开的 GUI**：那个标签页也会轮询并弹卡片，但游戏全屏时看不到浏览器；
  所以主要靠桌面窗口被叫出来。
- **提示音**：浏览器自动播放策略要求先和页面交互过；没点过页面时可能只有系统"叮"一声。
- **DSH 完全退出**：宿主进程没了，计时也停（"只要 DSH 没关闭"的边界就在这里）。
- 计时只在前端/宿主内存里：**彻底重启 DSH 会算新一轮**；刷新页面不丢。
